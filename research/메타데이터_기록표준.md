# 데이터 메타데이터 기록 표준 v1.0

## 기본 원칙

데이터 원장 한 행은 ‘제공기관 전체’가 아니라 **특정 데이터셋·통계표·문서**를 식별한다. 같은 목록에서 찾은 지표는 개별 표 ID 확보 전까지 후보 상태로 관리한다. 원본 URL, 파일 URL, API 조회 URL은 구분한다.

기본 양식: 데이터명 / 원본 URL / 제공기관 / 측정 단위 / 기준기간 / 갱신주기 / 제공방식 / 저작권 / 수집시각 / 검증상태.

CSV·XLSX·Open API는 제공방식이지 저작권 허락이 아니다. 무료·공개라는 이유만으로 재배포 허용으로 기록하지 않는다.

## 현 원장 필드

| 필드 | 의미·기록 규칙 |
| --- | --- |
| source_id | D01 등 고정 식별자. 이름·URL이 변경되어도 유지 |
| source_type | 공식통계·공공데이터·마이크로데이터·공시·공식보고서·결정자료·제재절차자료·기사 등 |
| data_name | 공식 명칭. 후보는 후보임을 명시 |
| provider | 작성·제공기관. 포털과 원 작성기관이 다르면 둘 다 기재 |
| original_url | 개별 공식 자료 페이지 우선. 기관 첫 화면만 있으면 확인단계를 낮춤 |
| url_level | 개별자료·서비스 / 공식목록 / 공식안내 / 기관포털 |
| news_questions | Q1~Q8에 대응하는 정수 배열. 배경문서는 빈 배열 허용 |
| measurement_unit | 원, kWh, kWh/가구, ℃, mm, 일, 지수 기준연도, % 등을 원문대로; 미확인 구분 |
| target_period | 수집 목표기간. 실제 확보기간과 혼동 금지 |
| coverage_verified | 원문에서 확인한 수록범위와 한계. 미확인은 그대로 표시 |
| update_frequency | 통계 공표주기와 포털 갱신주기를 구분해서 기재 |
| access_method | API·CSV·XLSX·HTML·PDF, 인증·신청·접속제한 여부 |
| verification_status | 설명확인·목록확인·경로확인·부분확인·검색확인·접속제한·원문미검증·후보 |
| metadata_collected_at | 메타데이터를 원장에 기록한 일괄 시각. ISO 8601, UTC의 Z 또는 +09:00 포함 |
| source_checked_on | 공식 페이지·검색 결과의 조사일. 웹 검색 캐시의 수집일과 다를 수 있음 |
| raw_data_collected_at | 원자료 다운로드 완료 시각. 다운로드하지 않았으면 null |
| raw_file_url | 원본 파일 또는 API 응답의 출처. 미확보 null; 인증키 제거 |
| local_raw_path | 실제 저장 원본 경로. 없으면 null |
| sha256 | 실제 저장 원본의 SHA-256. 없으면 null |
| license | 해당 자료에서 확인한 이용허락 내용. 미확인은 미확인으로 표시 |
| license_evidence_url | 이용허락 문구의 공식 근거 URL. 없으면 null |
| table_id | 통계표 식별자. 확인 전 null; 추측해서 채우지 않음 |
| item_codes / region_codes | 실제 요청·추출한 항목·지역코드. 미조회는 빈 배열 |
| query_parameters | 조회기간·지역·항목·페이지 조건. API 키·개인정보 제외; 미실행 null |
| source_updated_at | 제공기관이 표시한 수정일. 기준기간·발표일·다운로드일과 구분 |
| quality_notes | 정의·표본·분모·개편·집계·기준연도·비교 한계 |
| raw_collection_status | 현재 원자료 수집 상태. 이번 조사에서는 전 항목 ‘미수집’ |

## 실제 수집 이후 추가할 필드

- temporal_granularity: 일·월·분기·연.
- spatial_granularity, geography_vintage, coordinate_reference_system: 지점·시도·시군구, 경계 기준연도, 좌표계.
- population_definition, denominator: 조사 대상·제외대상, 가구·세대·계약·고객호수 등 분모.
- rows, observed_period_start, observed_period_end, missing_count, duplicate_count: 파일에서 직접 계산한 품질 요약.
- unit_multiplier, index_base_year, seasonal_adjustment, provisional_flag: 단위 배율, 가격지수 기준, 계절조정, 잠정치.
- revision_id, supersedes_id, release_date, document_event_date: 수정본 식별·대체 관계·공표일·사건일.
- document_case_id, procedural_stage, finality_verified: 사건번호·심사/의결/불복 등 단계·확정 여부.
- transformation_id, parent_source_ids, formula, weighting_method: 파생지표 재현에 필요한 계산 정보.

## 수집 완료 판정

‘공식 설명을 읽음’은 ‘원자료 수집 완료’가 아니다. 다음을 모두 확인한 뒤 상태를 변경한다.

1. 원자료 파일 또는 API 응답이 실제 저장되어 있고, 다운로드 시각·해시가 있다.
2. 필요한 기간·지역·세부항목·단위가 실제 응답에 있다.
3. 코드북과 이용조건을 확인했으며 분모·개편·결측 문제를 기록했다.
4. 앱에서 표시하는 수치가 어느 원본·버전·계산에서 나왔는지 추적할 수 있다.

이번 원장에는 이 판정을 통과한 신규 원자료가 없다. 접속에 실패한 기관의 비공개 여부나 데이터 부재를 단정하지 않는다.
