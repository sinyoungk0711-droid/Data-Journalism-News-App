# 기후의 청구서 — 데이터·문서 정보원 조사 원장

조사일: 2026년 11월 13일(한국시간). 메타데이터 일괄 기록시각: 2026-11-13T07:08:36Z (한국시간 16:08:36).

분석 기준기간은 **2016~2025년(완료된 10개 연도)**이다. ‘조사일로부터 정확히 10년’과 구분한다. 2026년 발표 문서는 분석기간에 관한 사후 자료 또는 현재 제도 설명으로 분류한다. 과거 행위기간과 발표시점은 별개다.

**27개 원장 항목(데이터·공간정보 후보 18, 문서 9)**을 기록했다. 이는 독립된 파일 27개를 확보했다는 뜻이 아니다. 같은 공식 목록에서 식별한 서로 다른 지표도 각각 항목으로 기록했다. 이번 작업은 정보원과 메타데이터 조사이며, 원자료 다운로드·API 실호출·전수 시계열 검증은 수행하지 않았다. 기존 뉴스앱에 수록된 값의 과거 수집시각도 새로 만들어 넣지 않았다.

## 조사에서 확인한 결정 사항

- 가계동향조사: 분기·연간 공표와 포털의 ‘수시 갱신’을 나누어 기록한다. 현행 KOSIS 소비지출 지표는 2019년부터 표시되므로 2016~2018년을 단순 연결하지 않는다. [현행 지표](https://kosis.kr/visual/nsportalStats/detailContents.do?listId=F&statJipyoId=3695&vStatJipyoId=5129), [자료 설명](https://www.data.go.kr/data/15113184/fileData.do)
- 한전 시군구 과거 파일의 공식 검색 설명은 2016~2017년이다. 10년 자료를 확보했다고 표시하지 않는다. [과거 파일](https://www.data.go.kr/data/15069679/fileData.do?recommendDataYn=Y)
- 한전 가구 평균 API(15101404)는 공식 카탈로그에서 명칭을 확인했으나 상세 명세와 연도별 응답은 검증하지 못했다. 외부 산업데이터 포털의 검색요약과 현재 상세 화면이 달라 그쪽의 라이선스·갱신일을 채택하지 않았다. [공식 카탈로그](https://www.data.go.kr/catalog/15101404/openapi.json)
- 에너지바우처 공시는 현재 2020~2024년 전국 발급가구 합계만 보인다. 시군구 취약 가구 지도의 분자로 바로 사용할 수 없다. [공시](https://www.energy.or.kr/front/conts/102017010000000.do)
- 기후정보포털의 이상기후 보고서 링크는 조사 당시 임시중단 안내로 연결됐다. 보고서는 기상청의 발간 발표 및 첨부 원문 경로를 다시 확보해야 한다. [조사 시 안내](https://www.climate.go.kr/notice.html?bname=abnormal&code=93)
- 지역 CPI는 가격 수준이 아니라 같은 기간의 상승률로 비교한다. 소득분위 평균 표로 가구별 부담 분포를 그리지 않는다. [KOSIS 지역비교 해설](https://kosis.kr/visual/economyBoard/economyJipyo.do?listId=124&unitySrvcId=640)

## 원자료 수집 시 운영 규칙

1. 공식 상세표·코드북을 확인해 표 ID, 항목코드, 지역코드, 조회 조건을 확정한다. 목록 URL만으로 ‘분석 준비 완료’ 처리하지 않는다.
2. 다운로드 시각(시간대 포함), 최종 다운로드 URL, 원본 파일명, 로컬 경로, SHA-256, 응답 행 수, 최소·최대 기준시점을 기록한다. API 인증키를 원장·공유 URL에 남기지 않는다.
3. 단위, 소득·지출의 모집단, 가격지수 기준연도, 관측지점 이력, 행정구역 개편을 확인한다. 잠정·확정·수정본은 덮어쓰지 않고 버전으로 남긴다.
4. 결측·비밀보호·미상·오류 플래그를 0으로 치환하지 않는다. 수집 실패도 요청 조건과 오류 요약을 남긴다.
5. 원본 통계와 파생지표는 분리한다. 모든 파생지표에 원본 ID·사용 버전·산식·분모·기간·집계방법을 연결한다.
6. 공시 정정, 제재절차와 의결, 기소와 유죄 확정, 사건개요와 결정 전문을 구분한다. 이 문서들은 수치 시계열과 별도로 사건 단위로 관리한다.
