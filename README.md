# Data-Journalism-News-App

# 기후의 청구서

기후변화와 생활물가·가구 에너지 부담을 탐색하는 데이터 저널리즘 뉴스앱입니다.

## 뉴스앱 열기



기존 배포본은 소유자 비공개 사이트여서 로그인이 필요할 수 있습니다.

## 앱 소스

[docs/index.html](docs/index.html) · [화면 스타일](docs/style.css) · [차트와 탐색 기능](docs/app.js)

별도 빌드 없이 동작하는 정적 웹앱입니다. 로컬에서 `docs` 폴더를 정적 웹 서버로 열 수 있습니다. GitHub Pages는 `main` 브랜치의 `/docs` 폴더를 게시 대상으로 사용합니다.

## 정보원·메타데이터 조사

- [데이터·문서 정보원 조사 원장](research/데이터_정보원_조사원장.md)
- [메타데이터 기록 표준](research/메타데이터_기록표준.md)
- [구조화 데이터 원장(JSON)](research/source-ledger.json)

분석 기준기간은 2016~2025년입니다. 원장에는 데이터·공간정보 후보 18개와 문서 9개 등 27개 항목이 있으며, 확인 상태와 미확인 사항을 구분했습니다.

## 현재 수록 범위

- 기사형 도입, 8종 뉴스 질문, 질문별 공유 링크
- 기상청 2025년 여름철 17개 관측지점의 폭염·열대야 비교와 CSV 다운로드
- 물가·전력·가계자료, 10년 시계열, 지역 지도·혼합지수는 아직 연결 전

관측값을 가상의 통계로 대체하지 않았으며, 자료가 없는 항목은 ‘자료 연결 전’으로 표시합니다. 이 저장소의 라이선스와 별개로 외부 데이터·문서에는 각 제공기관의 이용조건이 적용됩니다.
